# 步步｜個人工作推進與復盤系統

「步步」是一套離線優先的 Windows 桌面工作系統，將四條長期主軸轉換成每天可以開始、可以完成、也能留下紀錄的一小步。

## 第一階段已完成

- 四主軸候選任務：AI 能力、作品與職涯／研究與論文投稿／教學內容與課程資產／股票研究與投資系統
- 每日啟動：可用時間、精力與硬期限
- 固定 25 分鐘番茄鐘、正向超時、暫停原因、繼續執行
- 完成定義確認、未完成原因與 5 分鐘休息
- 專案總覽、每日收工復盤、基本專注統計
- Tauri SQLite 本機儲存；瀏覽器開發模式使用 localStorage
- JSON 資料匯出、亮／暗色外觀、桌面通知

## 第二階段已完成

- 每週復盤三步驟精靈：本週摘要、問題分析、下週規劃
- 星期日提醒與補提醒；未做完的那一週不會漏掉
- 未完成任務可保留、拆小或取消；拆小會換成一個 25 分鐘做得完的小步驟
- 星期日備份提醒與立即備份，預設寫到「文件\步步\backups」，可在設定中變更
- JSON 備份還原：先建立安全備份，再預覽並覆蓋；損壞或較新版本的檔案會被拒絕
- 每月復盤四步驟精靈：本月成果、趨勢比較、專案去留與下月三個主要成果
- 專案可在月復盤設為繼續、暫停、取消或完成並封存；非推進中的專案不會進入日常推薦
- 從專案播放鍵直接進入番茄鐘，開始與時間到使用低音量柔和雙音提示
- 任務建立後可修改內容；已完成項目可修正實際分鐘與完成日期時間，並同步所有統計
- 未符合完成定義時，可選擇只留下本次時間、不紀錄原因
- 連續行動日數改由實際專注紀錄推算
- 每日復盤送出後立即生成「今日收工卡」，保存當日成果、專注時間、MVP、明日種子與劇情轉折
- 收工卡新增感謝日記，長期保存在本機，可從復盤中心按日期重新查看或更新
- 收工卡可透過原生「另存新檔」下載為 Markdown，方便日後搜尋、整理與分享
- 歷史收工卡可指定日期或全選，批次匯出 CSV、JSON 或 Markdown；CSV 採一日一列，適合後續製作趨勢圖
- 批次匯出預設一次產生三種格式；桌面版只需選一次資料夾，即可得到 CSV、JSON、Markdown 三個檔案
- 今日與歷史收工卡都可重新編輯 MVP、劇情轉折、明日種子與感謝日記，原始統計快照不會被重算
- 快速新增改為智慧拆解：25 分鐘內保留一項，較大成果依主軸生成一個父任務與三個 25 分鐘小任務
- 拆解預覽中的父任務、小任務、完成定義、第一個動作、預估時間與順序都可修改，也可增刪步驟
- 小任務依序解鎖；全部完成後父任務自動完成，父任務不重複計入完成數與專案進度

開發過程與待辦見 [工作日誌](docs/工作日誌.md)，收工卡欄位與圖表規劃見 [收工卡資料格式與視覺化](docs/收工卡資料格式與視覺化.md)。

## 開發指令

```powershell
npm install
npm run dev
```

執行檢查：

```powershell
npm run build
npm test
```

Windows 桌面模式需先安裝 Rust stable-msvc、Microsoft C++ Build Tools 與 WebView2：

```powershell
npm run tauri dev
```

若尚未安裝工具鏈，可直接雙擊 `install-desktop-toolchain.cmd`，並在 Windows 權限提示選擇「是」。腳本只會從 Rust 與 Microsoft 官方來源安裝必要元件。

產生 NSIS 安裝程式：

```powershell
npm run tauri build
```

也可以在 PowerShell 執行 `./build-release.ps1`，它會依序執行安裝檢查、前端建置、測試與 Tauri 打包。

## 資料原則

- 正式桌面程式的資料保存在本機 SQLite，不需登入或連線雲端。
- 瀏覽器模式只供開發與預覽，不與正式桌面資料共用。
- 建議固定使用「匯出資料」保留可攜式 JSON 備份。

完整開發歷程與需求變更請見 [工作日誌](docs/工作日誌.md)。
