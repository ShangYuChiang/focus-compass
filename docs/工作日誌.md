## 2026-08-19　智慧任務拆解與 0.9.0 打包

### 完成

- 快速新增改成兩階段流程：先填整體成果，再檢視 AI 建議的小任務，確認後才寫入。
- 25 分鐘內的任務保留為一項；50 分鐘以上的成果依四個主軸產生父任務與三個 25 分鐘小任務。
- 每個小任務都有名稱、完成定義、第一個動作與預估時間。
- 生成後可修改父任務與全部小任務，可增加、刪除、上下排序；重新生成前會警告，不直接覆蓋手動修改。
- 保存後仍可編輯任務名稱、完成定義、第一個動作、主軸、專案、優先度、預估時間與小任務順序。
- 父任務不可直接計時；小任務依序解鎖，前一步完成或取消後才推薦下一步。
- 全部小任務完成時父任務自動完成；父任務不重複計入今日、週、月完成數與專案進度。
- 狀態資料升級至 v5；舊任務自動視為可執行任務並補上 25 分鐘預估，不遺失既有內容。

## 2026-08-18　備份還原與 0.2.0 打包

### 目標

接續 Phase 5，完成規劃書 §18 的 JSON 備份還原，並確保覆蓋目前資料前一定先留下安全備份。

### 完成

- 新增 JSON 備份選取、內容預覽與明確確認畫面。
- 還原前強制建立 `focus-compass-pre-restore-*.json`；安全備份失敗時完全不寫入還原資料。
- 僅接受 20 MB 以下、UTF-8、版本相容且核心資料結構完整的步步 JSON。
- 舊版 v1 備份先經既有 migration 升級；高於目前版本的備份會拒絕並提示先更新程式。
- 還原中的舊計時不累加離線時間；過期休息狀態回到 idle，孤立的 active 任務回到待執行。
- 自訂備份資料夾視為本機裝置設定，不會被其他電腦的備份路徑覆蓋。
- 桌面 SQLite 使用嚴格寫入；寫入失敗不會假裝還原成功。
- Rust 端只讀取使用者透過原生選檔器選中的 JSON，不開放廣泛檔案系統權限。
